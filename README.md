# Fateme Sajedi – personal website

Live at **https://fatemesajedi.github.io**

## How to edit (no coding)

1. Go to **https://app.pagescms.org** and sign in with GitHub.
2. Open the repository `fatemesajedi/fatemesajedi.github.io`.
3. Use the menu on the left: *About me*, *Conferences & Events*, *Publications*, *Research projects*, *News*.
4. Click **Save**. The website updates automatically within ~1–2 minutes.

## Where things live

| What | File / folder |
|---|---|
| Name, bio, links, education | `_data/profile.yml` |
| Conferences | `_conferences/` |
| Publications | `_publications/` |
| Research projects | `_projects/` |
| News items | `_news/` |
| Photos | `assets/images/` |
| PDFs (CV, papers) | `assets/files/` |
| Menu | `_data/navigation.yml` |
| Design (colors, fonts) | `assets/css/style.css` |
| Control panel setup | `.pages.yml` |

Tip: resize phone photos to ~1600 px wide before uploading. Smaller files make the site faster.
